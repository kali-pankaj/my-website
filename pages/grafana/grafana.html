01 — Overview

What Grafana actually is

Grafana is a visualization and observability layer, not a database. It connects to time-series databases, logging systems, and tracing backends, then lets you build dashboards on top of them. Originally built by Torkel Ödegaard in 2014 as an offshoot of work on Graphite, it's now developed by Grafana Labs and is used across DevOps, SRE, IoT, and business-analytics teams. Grafana OSS is free and self-hosted; Grafana Cloud is the managed version.

CONCEPT

Dashboards

A dashboard is a collection of panels arranged on a grid — the unit you actually look at and share.

CONCEPT

Panels

The individual visualization: a time-series graph, a table, a gauge, a heatmap, or a single stat.

CONCEPT

Data sources

Plugins that connect Grafana to where your data actually lives — Prometheus, Loki, SQL, and more.

CONCEPT

Alerting

Rules that evaluate query results on a schedule and route notifications when thresholds are crossed.

CONCEPT

Plugins

Panels, data sources, and apps built by Grafana Labs or the community to extend core functionality.

CONCEPT

Explore

An ad-hoc query workspace for digging into logs and metrics outside of a fixed dashboard layout.

02 — Architecture

How the pieces fit together

Grafana itself stores no metrics. It sends queries to your data sources at render time (or on a refresh interval), then renders the response as a panel in the browser.

Data sources Prometheus / Loki / SQL / CloudWatch
→
Grafana server Query, transform, render
→
Browser Dashboards, alerts, Explore

04 — Getting started

Installing Grafana

Pick a path. All packages come from the official download page linked in the resources panel below.

# pulls and runs Grafana OSS, exposed on port 3000 docker run -d -p 3000:3000 --name=grafana grafana/grafana-oss

Fastest way to try Grafana locally. Default login is admin / admin on first run.

# Debian / Ubuntu — adds the official APT repo, then installs sudo apt-get install -y apt-transport-https software-properties-common wget -q -O - https://apt.grafana.com/gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/grafana.gpg echo "deb [signed-by=/usr/share/keyrings/grafana.gpg] https://apt.grafana.com stable main" | sudo tee /etc/apt/sources.list.d/grafana.list sudo apt-get update && sudo apt-get install grafana

Exact package names for RHEL/Fedora/SUSE and .deb/.rpm downloads are on the official download page.

# via Homebrew brew update brew install grafana brew services start grafana

A standalone macOS binary is also available from the official download page if you'd rather not use Homebrew.

# download the Windows installer or .zip from the official page, then: cd grafana-<version>\bin .\grafana-server.exe

Grafana runs as a Windows service or a standalone binary; both installers are on the official download page.

→ After install, Grafana listens on http://localhost:3000 by default.
